One line, at most 200 characters, that makes a meeting-that-should-have-been-an-email funny. The program writes the entry to `/output/entry.txt`.

## The entry

> Nine people spent an hour listening to someone read an email aloud, then scheduled a follow-up meeting to discuss replying by email.

## Run

```sh
node main.ts
```
